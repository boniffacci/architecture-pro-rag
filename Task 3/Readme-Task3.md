# Pokemon RAG — Индексация и поиск по базе знаний

## Описание

Этот скрипт создаёт векторный индекс для базы знаний о покемонах и позволяет выполнять поиск по содержимому документов с помощью эмбеддингов.

Функционал скрипта:

1. Загружает текстовые файлы из папки `knowledge_base`.
2. Разбивает текст на чанки с помощью `RecursiveCharacterTextSplitter` (chunk_size=800, overlap=150).
3. Генерирует эмбеддинги для каждого чанка с моделью **`sentence-transformers/all-MiniLM-L6-v2`**.
4. Сохраняет индекс в **Chroma** (папка `chroma_db`).
5. Позволяет выполнять поиск по семантике с использованием `similarity_search`.

---

## Используемые модели и библиотеки

- **Модель эмбеддингов:** `sentence-transformers/all-MiniLM-L6-v2`  
- **Векторное хранилище:** Chroma  
- **Текстовый сплиттер:** `RecursiveCharacterTextSplitter` из LangChain  
- **Python-библиотеки:** `langchain`, `tqdm`, `uuid`, `pathlib`

---

## База знаний

- Папка: `knowledge_base/`
- Формат файлов: `.txt`  
- Пример содержимого: описания покемонов, их типов, способностей и движений.

---

## Индекс

- **Количество чанков:** зависит от размера текстов в `knowledge_base`; примерно **800 символов на чанк с 150 символами перекрытия**.  
- Каждый чанк хранится как `Document` с метаданными: имя исходного файла и номер чанка.
