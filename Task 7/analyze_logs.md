- Retriever возвращает релевантные по форме, но не по смыслу документы.

## 6. Рекомендации по улучшению базы знаний

### 6.1 Улучшение индексации
- Добавить порог схожести (например, `cosine_similarity < 0.4 → пропустить результат`).
- Ввести метаданные для сущностей (type, move, ability, stat).
- Исключить дублирующиеся документы из ChromaDB.

### 6.2 Улучшение обработки ответов
- Ввести строгую постобработку для отсутствующих данных:
- Добавить тест на "осмысленность" ответа (длина > 3 и нет ключевых слов вроде “no context”, “not mentioned” → считать неуспешным).

### 6.3 Расширение набора данных
- Добавить больше документов по новым сущностям (Pokémon второго поколения).
- Включить примеры обобщённых вопросов с правильной реакцией ("Не знаю").

### 6.4 Расширение набора данных
- Автоматизировать ежедневный прогон golden_questions.json через cron.
- Сохранять результаты в logs.jsonl и строить отчёт покрытия.
